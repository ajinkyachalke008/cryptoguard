## 🚀 Key Modules & Capabilities

### 1. 🕸️ Institutional Forensic Graph Explorer
*Deep Multi-Hop Transaction Graph & Flow Analysis Engine*
- **5-Hop Deep Breadth-First-Search (BFS)**: Unveils full counterparty networks up to 5 hops deep (reaching 45–50+ interconnected nodes), uncovering mule accounts, OTC intermediaries, decentralized dark pools, cold vaults, and cross-chain bridge deposits.
- **Controlled 4-Color Palette Variation**: Deterministic topological color assignment (`#eab308` Gold/Yellow, `#10b981` Emerald Green, `#ef4444` Crimson Red, `#3b82f6` Cobalt Blue), preventing single-color monotony while preserving critical entity accents (Tornado Cash, Binance, Uniswap, Stargate).
- **5 Multi-View Visual Modes**:
  - `3D Spatial Constellation`: Immersive WebGL node network with depth navigation and camera controls.
  - `2D Force-Directed`: Organic physics-based force layout with dynamic spring links and collision buffers.
  - `Hierarchical Tree`: Upstream-to-downstream fund propagation view.
  - `Radial Ego`: Ego-centric concentric orbital hops centered around the primary target.
  - `Risk Matrix`: Heatmap-oriented distribution classifying wallets by severity and flow velocity.
- **Sub-Second Hop-Depth Slider**: Instant slider adjustments with cached coordinate preservation and zero UI freeze.
- **Dynamic Dossier Side-Drawer**: Instant inspection of addresses, transaction counts, cumulative volume, risk flags, and direct copyable explorer links.

## ⚡ Quickstart & Local Setup

### Prerequisites
- **Node.js**: `v18.18+` or `v20+`
- **npm** or **pnpm**
- **Git**

### Installation

1. **Clone the repository:**
   ```bash
   git clone https://github.com/ajinkyachalke008/cryptoguard.git
   cd cryptoguard
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Configure Environment Variables:**
   Create a `.env.local` file in the root directory:
   ```env
   # Turso Database (optional - mock fallback active by default)
   TURSO_DATABASE_URL=libsql://your-database-name.turso.io
   TURSO_AUTH_TOKEN=your-turso-auth-token

   # JWT Secret for Authenticated Sessions
   JWT_SECRET=your-super-secure-jwt-secret-key-at-least-32-chars

   # OpenAI API Key (optional - mock narrative active if omitted)
   OPENAI_API_KEY=sk-...
   ```

4. **Launch Development Server:**
   ```bash
   npm run dev
   ```

5. **Open Browser:**
   Navigate to [http://localhost:3000](http://localhost:3000) to view CryptoGuard.
